# BookHaven
Open the folder in VS Code and run with Live Server (or copy to XAMPP `htdocs`) and open `index.html`.
Data lives in localStorage (prefix `bh_`). Demo logins: **admin / admin123**, **demo / demo1234**.
Promo codes: BOOK10, SAVE50. Payments are simulated; card numbers are never stored. Passwords use a demo-only encoding — replace with server-side hashing (PHP `password_hash`) when adding MySQL.
